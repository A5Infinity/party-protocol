# 2. Propositions et votes

Une proposition décrit une action puis traverse une fenêtre de vote. Les seuils, pouvoirs et délais déterminent si l’action peut être exécutée par le groupe.

Ce chapitre relie le mécanisme aux contrats concernés et explicite les invariants utiles à un intégrateur.
